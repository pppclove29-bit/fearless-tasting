# Play 스토어 등록정보 초안

복붙용 초안. 문구는 [product-direction.md](product-direction.md)의 포지셔닝
("공개 맛집 플랫폼"이 아니라 **프라이빗 그룹 도구**)에 맞춰 작성했다.
검색 키워드는 "맛집 검색"이 아니라 "맛집 기록 · 공유 · 리스트"를 노린다.

## 앱 이름 (30자 이내)

```
무모한 시식가 - 우리끼리 맛집 기록
```

대안: `무모한 시식가 : 맛집 리스트 공유` / `무모한 시식가 - 친구랑 맛집 기록`

## 짧은 설명 (80자 이내)

```
친구·연인·팀과 함께 만드는 우리만의 맛집 리스트. 광고 없는 진짜 후기만 모아요.
```
(38자)

대안:
```
단톡방에 흩어진 맛집, 우리 방에 모아 기록하세요. 광고 없는 솔직한 후기.
```

## 자세한 설명 (4000자 이내)

```
🍽️ 우리끼리 보는 맛집 리스트

"저번에 갔던 그 집 어디였지?"
단톡방을 아무리 뒤져도 안 나오는 그 맛집, 이제 우리 방에 기록하세요.

무모한 시식가는 친구·연인·가족·회사 팀이 함께 쓰는 비공개 맛집 기록장입니다.
검색해서 나오는 광고·협찬 리뷰 말고, 우리가 직접 가보고 남긴 솔직한 평가만 쌓입니다.


✅ 이런 분들께

· 단톡방에 맛집 링크를 던져놓고 매번 다시 찾는 분
· 지도 앱 즐겨찾기가 뒤죽박죽이라 정리가 안 되는 분
· 데이트 코스로 갔던 식당을 기록해두고 싶은 커플
· 팀 점심·회식 장소를 매번 새로 고민하는 직장인


📌 주요 기능

1. 방 만들고 초대하기
초대 코드나 링크 하나면 끝. 카카오톡으로 친구를 부르세요.
회식·데이트·신혼·가족·친구 등 상황별 템플릿을 고르면 방이 바로 세팅됩니다.

2. 식당 등록부터 리뷰까지 한 번에
카카오맵·네이버 검색으로 식당을 찾아 등록하고, 방문 기록과 리뷰까지 한 화면에서.
별점만 눌러도 기록은 완성됩니다.

3. 우리끼리만 보는 솔직한 평가
맛·가성비·서비스·청결·접근성까지 원하는 만큼 세부 평가.
"또 먹고 싶은 메뉴", "다음에 먹어볼 메뉴"도 남길 수 있어요.
같은 식당에 대한 멤버별 평가를 나란히 비교해 보세요.

4. 오늘 뭐 먹지? 투표로 정하기
후보를 올리고 링크만 보내면 끝. 받는 사람은 가입 없이 바로 투표할 수 있습니다.
회식 장소 정하다 대화가 산으로 가는 일이 없어집니다.

5. 우리 방의 데이터가 쌓입니다
카테고리·지역 분포, 요일별 방문 패턴, 평점 TOP/BOTTOM, 재방문율까지.
1년 뒤 우리가 어떤 맛집을 좋아했는지 한눈에 보입니다.


🔒 프라이버시

방은 기본적으로 비공개입니다. 초대받은 멤버만 볼 수 있습니다.
방장이 직접 공개로 전환하지 않는 한, 어떤 기록도 외부에 노출되지 않습니다.


💸 완전 무료

회원가입은 카카오·네이버 계정으로 3초면 됩니다.
기록도, 초대도, 통계도 전부 무료입니다.


지금 시작해서, 우리만의 맛집 지도를 만들어보세요.
```

## 스크린샷 구성 (폰 최소 2장, 권장 5장)

앱 화면을 그대로 올리지 말고 **상단에 한 줄 카피를 얹은 목업**으로 만든다.
현재 UI가 그레이스케일이라 그냥 캡처하면 스토어에서 눈에 띄지 않는다.

| # | 화면 | 얹을 카피 |
| --- | --- | --- |
| 1 | 방 상세 (식당 목록, 썸네일 보이는 상태) | 우리끼리 보는 맛집 리스트 |
| 2 | 식당 등록 위저드 | 검색 한 번으로 기록 완성 |
| 3 | 리뷰 세부 평점 | 광고 없는 진짜 평가 |
| 4 | 투표 화면 | 오늘 뭐 먹지? 링크로 투표 |
| 5 | 통계 탭 | 우리 방의 1년이 데이터로 |

> 스크린샷용 방에는 **식당 8곳 이상 + 사진 + 리뷰**를 미리 채워둘 것.
> 빈 화면 캡처는 설치율을 직접 깎는다.

## 그래픽 자산

- 앱 아이콘 512×512 (PNG, 알파 없음)
- 그래픽 이미지 1024×500
- 폰 스크린샷 최소 2장 (16:9 또는 9:16)

## 데이터 안전 양식 답변 초안

| 항목 | 수집 | 용도 | 필수 |
| --- | --- | --- | --- |
| 이메일 주소 | O | 계정 식별 (카카오·네이버 OAuth) | 필수 |
| 이름/닉네임 | O | 방 내 표시 | 필수 |
| 프로필 사진 | O | 방 내 표시 | 선택 |
| 사진 | O | 리뷰 이미지 | 선택 |
| 앱 활동(사용자 생성 콘텐츠) | O | 방·식당·리뷰 기록 | 필수 |
| 기기 ID | O | 푸시 알림(FCM) | 선택 |
| 위치 | X | — | — |

- 전송 구간 암호화: 예 (HTTPS)
- 데이터 삭제 요청 가능: 예 → `https://musikga.kr/profile/account`
- 광고 목적 공유: 아니오

## 앱 액세스 권한 (심사용)

로그인이 카카오·네이버 OAuth뿐이라 심사자가 자력으로 진입할 수 없다.
아래를 반드시 기입한다.

```
로그인 방법: 카카오 계정으로 로그인
테스트 계정: (전용 카카오 계정 ID)
비밀번호: (해당 계정 비밀번호)
안내: 앱 실행 → "카카오로 시작하기" → 위 계정으로 로그인하면
      샘플 데이터가 들어있는 방에 바로 진입합니다.
```

> 해당 계정에 식당·리뷰·투표 샘플 데이터를 미리 채워둘 것.
> 2단계 인증은 꺼둘 것.
