# Play 스토어 등록정보 초안

복붙용 초안. 문구는 [product-direction.md](product-direction.md)의 포지셔닝
("공개 맛집 플랫폼"이 아니라 **프라이빗 그룹 도구**)에 맞춰 작성했다.
검색 키워드는 "맛집 검색"이 아니라 "맛집 기록 · 공유 · 리스트"를 노린다.

## 앱 이름 (30자 이내)

```
무모한 시식가 - 우리끼리 맛집 기록
```

대안: `무모한 시식가 : 맛집 리스트 공유` / `무모한 시식가 - 친구랑 맛집 기록`

## 짧은 설명 (80자 이내)

```
친구·연인·팀과 함께 만드는 우리만의 맛집 리스트. 광고 없는 진짜 후기만 모아요.
```
(38자)

대안:
```
단톡방에 흩어진 맛집, 우리 방에 모아 기록하세요. 광고 없는 솔직한 후기.
```

## 자세한 설명 (4000자 이내)

```
🍽️ 우리끼리 보는 맛집 리스트

"저번에 갔던 그 집 어디였지?"
단톡방을 아무리 뒤져도 안 나오는 그 맛집, 이제 우리 방에 기록하세요.

무모한 시식가는 친구·연인·가족·회사 팀이 함께 쓰는 비공개 맛집 기록장입니다.
검색해서 나오는 광고·협찬 리뷰 말고, 우리가 직접 가보고 남긴 솔직한 평가만 쌓입니다.


✅ 이런 분들께

· 단톡방에 맛집 링크를 던져놓고 매번 다시 찾는 분
· 지도 앱 즐겨찾기가 뒤죽박죽이라 정리가 안 되는 분
· 데이트 코스로 갔던 식당을 기록해두고 싶은 커플
· 팀 점심·회식 장소를 매번 새로 고민하는 직장인


📌 주요 기능

1. 방 만들고 초대하기
무모한 시식가는 둘 이상이 함께 쓰는 기록장이에요. 방을 만들면 같이 먹을 사람부터 불러주세요.
카카오톡으로 링크를 보내거나, 옆에 있다면 QR 코드를 찍게 하면 끝.
링크를 받은 친구는 가입 전에도 어떤 방인지 미리 볼 수 있어요.
회식·데이트·신혼·가족·친구 등 상황별 템플릿을 고르면 방이 바로 세팅됩니다.

2. 식당 등록부터 리뷰까지 한 번에
카카오맵·네이버 검색으로 식당을 찾아 등록하고, 방문 기록과 리뷰까지 한 화면에서.
별점만 눌러도 기록은 완성됩니다.

3. 우리끼리만 보는 솔직한 평가
맛·가성비·서비스·청결·접근성까지 원하는 만큼 세부 평가.
"또 먹고 싶은 메뉴", "다음에 먹어볼 메뉴"도 남길 수 있어요.
같은 식당에 대한 멤버별 평가를 나란히 비교해 보세요.

4. 어디 갈지 투표로 정하기
후보를 올리고 링크만 보내면 끝. 받는 사람은 가입 없이 바로 투표할 수 있습니다.
회식 장소 정하다 대화가 산으로 가는 일이 없어집니다.

5. 오늘 뭐 먹지? 추천 받기
메뉴가 안 정해지는 날엔 버튼 한 번.
위시리스트에서 하나 뽑거나, 우리가 별점 높게 준 단골을 다시 추천하거나,
내 주변·아직 안 먹어본 종류·평소 잘 안 가는 방향의 새 식당을 찾아줍니다.
마음에 들면 바로 위시리스트에 담아두세요.

6. 우리 방의 데이터가 쌓입니다
카테고리·지역 분포, 요일별 방문 패턴, 평점 TOP/BOTTOM, 재방문율까지.
1년 뒤 우리가 어떤 맛집을 좋아했는지 한눈에 보입니다.


🔒 프라이버시

방은 기본적으로 비공개입니다. 초대받은 멤버만 볼 수 있습니다.
방장이 직접 공개로 전환하지 않는 한, 어떤 기록도 외부에 노출되지 않습니다.


💸 완전 무료

회원가입은 카카오·네이버 계정으로 3초면 됩니다.
기록도, 초대도, 통계도 전부 무료입니다.


지금 시작해서, 우리만의 맛집 지도를 만들어보세요.
```

## 데이터 보안 양식 답변 (2026-11-11 코드 기준으로 갱신)

Play Console → 앱 콘텐츠 → 데이터 보안. 질문 순서대로.

**1. 데이터 수집 및 보안**
- 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? → **예**
- 전송 중 데이터가 암호화되나요? → **예** (모든 통신 HTTPS)
- 사용자가 데이터 삭제를 요청할 수 있나요? → **예** (앱 안 프로필 → 계정에서 즉시 탈퇴)
- 계정 삭제 URL → `https://musikga.kr/profile/account`

**2. 수집하는 데이터 유형** ("공유"는 전부 아니오 — 아래 외부 서비스는 모두 우리를 대신해 처리하는 서비스 제공업체라 Play 기준 공유가 아니다)

| Play 분류 | 항목 | 수집 | 필수/선택 | 목적 | 근거 |
| --- | --- | --- | --- | --- | --- |
| 개인 정보 | 이메일 주소 | 예 | 필수 | 계정 관리 | 카카오·네이버 로그인 |
| 개인 정보 | 이름 | 예 | 필수 | 앱 기능, 계정 관리 | 닉네임 (방 안에 표시) |
| 개인 정보 | 사용자 ID | 예 | 필수 | 계정 관리 | 카카오·네이버 계정 식별자 |
| 사진 및 동영상 | 사진 | 예 | 선택 | 앱 기능 | 프로필·식당·리뷰 사진 (Cloudflare R2 저장) |
| 위치 | 대략적인 위치 | 예 | 선택 | 앱 기능 | 근처 위시리스트, "내 주변" 추천 |
| 위치 | 정확한 위치 | 예 | 선택 | 앱 기능 | 위와 같음 (`ACCESS_FINE_LOCATION`) |
| 앱 활동 | 기타 사용자 생성 콘텐츠 | 예 | 필수 | 앱 기능 | 방·식당·방문·리뷰·투표 기록 |
| 앱 활동 | 앱 상호작용 | 예 | 필수 | 분석 | Google Analytics (앱 번들에 GA 포함 확인) |
| 기기 또는 기타 ID | 기기 ID | 예 | 선택 | 앱 기능 | 푸시 알림 토큰 (Firebase Cloud Messaging) |
| 개인 정보 | 이메일 주소 (문의) | 예 | 선택 | 고객 지원 | 문의 폼에 직접 입력 |

**위치를 "예"로 바꾼 이유**: 좌표를 우리 서버에 저장하지는 않지만, "내 주변" 추천에서 카카오 장소 검색으로
기기의 좌표가 전송된다. Play는 "기기 밖으로 전송"이면 수집으로 본다 (일시적 처리 여부 질문에는 **예, 일시적으로 처리** 선택).

**수집하지 않음**: 전화번호·주소·결제·연락처·메시지·건강·파일·캘린더·웹 기록·오류 로그(크래시 수집 SDK 없음).
**광고**: 없음 (`PUBLIC_AD_CLIENT` 비어 있음, 앱 번들에 AdSense 없음 확인) → 광고 ID 수집 안 함.

## 앱 액세스 권한 (심사용)

로그인이 카카오·네이버 OAuth뿐이라 심사자가 자력으로 진입할 수 없다.
아래를 반드시 기입한다.

```
로그인 방법: 카카오 계정으로 로그인
테스트 계정: (전용 카카오 계정 ID)
비밀번호: (해당 계정 비밀번호)
안내: 앱 실행 → "카카오로 시작하기" → 위 계정으로 로그인하면
      샘플 데이터가 들어있는 방에 바로 진입합니다.
```

> 해당 계정에 식당·리뷰·투표 샘플 데이터를 미리 채워둘 것.
> 2단계 인증은 꺼둘 것.
